# Demo corpus

Every document in this directory is synthetic teaching material created for the RAG demo. It is not an ICAR, state agricultural university, KVK, IMD, or government recommendation and must not be used for farming decisions. The deliberately conflicting notes and embedded prompt-injection text are test fixtures.

Add real documents to `data/raw/` and an adjacent `<filename>.<extension>.meta.json` sidecar. See the project README for the required metadata fields and rebuild command.

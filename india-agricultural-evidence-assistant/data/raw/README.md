# Curated reference notes

This directory contains concise, curator-written summaries of public agricultural
research pages and reports to seed search testing. Each summary has a neighboring
metadata sidecar with the original source URL and known context. They are not full
source reproductions, current farm recommendations, or a replacement for the linked
sources.

Add locally curated PDF, Markdown, or UTF-8 text sources here with a neighboring
`<filename>.<extension>.meta.json` sidecar. Record only source details supported by the
document; leave unknown metadata blank and never mark generated examples as official.

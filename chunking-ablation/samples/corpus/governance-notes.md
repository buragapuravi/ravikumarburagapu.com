# Governance Notes

Responsible data work begins with a permitted source, a clear purpose, and an owner who can answer questions about the material. Data access should be limited to approved identities. Derived indexes and caches can preserve information from source files and should be included in retention and deletion reviews.

Credentials belong in a secret manager rather than an application repository. Sensitive text should only be sent to a model provider after its endpoint and data terms have been approved. Public availability alone does not establish permission to reuse a document.

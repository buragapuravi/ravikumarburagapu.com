# Model Evaluation Notes

Model evaluation compares predictions with documented references and source material. A human reviewer can inspect borderline cases that automated checks score inconsistently. A second evaluator may disagree, so annotation rules and adjudication procedures should be recorded.

Latency and cost depend on model size, context length, provider rates, hardware, and network conditions. Local retrieval timing should not be presented as total hosted inference latency. Reproducible reports identify which parts of a request were included in each timer.
